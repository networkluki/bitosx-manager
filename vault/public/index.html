Sign in

Your account password signs you in here. It is not your vault master password, and your vault is never sent to this site.

This account has two-factor authentication. Enter the 6-digit code from your authenticator app, or one of your recovery codes. The code goes only to the BitosX server, together with the one-time token it issued for this sign-in.

Two-factor authentication

A code from an authenticator app (TOTP) in addition to your account password when you sign in. It protects the account sign-in only; the vault master password is a separate thing and stays as it is.

Add this secret to your authenticator app (type it, or paste the full link into an app that accepts one), then enter the code the app shows to confirm. The secret is shown once and is not kept by this page.

Delete this account

        
Permanently deletes the account, every session and the encrypted vault stored on the server. A vault file on your own devices is not touched. This cannot be undone; the address can register again from scratch.

        

        

          

            
            
          

          

            
          

          

            
          

        

      


      

        
Your vault

        
The server stores your vault exactly as the desktop app encrypted it and cannot open it. It is opened in this browser with the vault's master password, which is never sent anywhere. Changes you make here are encrypted in the browser with the same vault key and uploaded only when you press Save to server.
